# Retail Sales EDA

## OASIS INFOBYTE — Data Analytics Internship | Task 1

### Project Overview

This project performs Exploratory Data Analysis (EDA) on retail sales data to identify sales trends, customer patterns, product category performance, and useful business insights.

## Objective

The objective is to analyze retail sales data using Python and identify meaningful patterns that can support business decision-making.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Dataset inspection
- Data cleaning
- Missing-value analysis
- Duplicate-value analysis
- Date conversion
- Descriptive statistics
- Mean, median, mode, and standard deviation
- Monthly sales trend
- Quarterly sales trend
- Sales by product category
- Sales by gender
- Sales by age group
- Product category transaction analysis
- Correlation analysis
- Correlation heatmap
- Average transaction value by product category
- Business insights and recommendations

## Key Findings

- Q4 recorded the highest quarterly sales.
- Electronics generated the highest total sales.
- Clothing recorded the highest number of transactions.
- Customers aged 46–55 generated the highest sales.
- Female customers generated slightly higher sales than male customers.
- Beauty had the highest average transaction value.

## Business Recommendations

1. Maintain sufficient inventory for high-performing Electronics and Clothing categories.
2. Target customers aged 46–55 with personalized offers.
3. Use bundle offers and cross-selling to increase Clothing's average transaction value.
4. Use high-performing months and quarters for promotional and inventory planning.

## Dataset Limitation

The dataset does not contain an individual Product Name or Product ID column. Therefore, a genuine Top 10 individual-product analysis could not be performed. Product Category was used for the available product-level analysis.
