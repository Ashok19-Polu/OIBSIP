# Customer Segmentation Analysis

### OASIS INFOBYTE — Data Analytics Internship | Task 2

## 📌 Project Overview

Customer segmentation is the process of grouping customers based on similar purchasing behaviour. This project applies **RFM (Recency, Frequency, Monetary) analysis** and **K-Means clustering** to segment customers from an e-commerce transaction dataset.

The objective is to identify distinct customer groups and generate actionable insights that can help businesses develop targeted marketing strategies.

---

## 🎯 Objective

The main objectives of this project are to:

* Analyze customer purchasing behaviour.
* Calculate Recency, Frequency, and Monetary (RFM) metrics.
* Identify meaningful behavioural features for customer segmentation.
* Standardize the features before clustering.
* Determine an appropriate number of customer segments using the Elbow Method.
* Apply K-Means clustering to group customers.
* Visualize and profile the resulting customer segments.
* Provide marketing recommendations for each segment.

## 🔍 Project Methodology

### 1. Data Loading and Inspection

The dataset was loaded using Pandas and inspected to understand its structure, data types, missing values, and transaction-level information.

Data preparation was performed before calculating customer-level metrics.

### 2. RFM Analysis

Customer behaviour was measured using three RFM metrics:

| Metric        | Description                                              |
| ------------- | -------------------------------------------------------- |
| **Recency**   | Number of days since the customer's most recent purchase |
| **Frequency** | Number of purchases made by the customer                 |
| **Monetary**  | Total amount spent by the customer                       |

These metrics provide a behavioural representation of each customer.

### 3. Feature Standardization

Since RFM features can have different numerical scales, **StandardScaler** from Scikit-learn was used to standardize the features before applying K-Means clustering.

### 4. Elbow Method

The **Elbow Method** was used to evaluate different values of K and identify a suitable number of clusters for the customer segmentation model.

### 5. K-Means Clustering

The standardized RFM features were used as input to the **K-Means clustering algorithm**.

Customers with similar purchasing behaviour were grouped into the same cluster.

### 6. Cluster Visualization

The customer clusters were visualized using scatter plots to understand the relationship between different RFM features.

### 7. Cluster Profiling

The resulting clusters were analyzed using their average RFM values to understand the characteristics of each customer group.

### 8. Customer Distribution

A bar chart was created to show the number of customers belonging to each cluster.

## 💡 Business Insights

The customer segments can be used to develop targeted marketing strategies.

Examples of segment-based actions include:

* **High-value customers:** Provide loyalty rewards, exclusive offers, and personalized experiences.
* **Recently active customers:** Encourage repeat purchases through targeted promotions.
* **Low-frequency or low-value customers:** Use re-engagement campaigns and personalized discounts.
* **At-risk customers:** Target customers with high previous spending but low recent activity with retention campaigns.

The specific characteristics of each segment should be interpreted from the RFM averages generated by the notebook.
